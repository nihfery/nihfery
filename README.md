## About Me

I'm **Mohammad Fery Salim**, a Full-Stack Developer based in Bandung, Indonesia. I build modern web applications, Go-based microservices, and Web3 systems across frontend development, backend services, blockchain integration, databases, and UI/UX design.

Currently, I work as a **Full-Stack Developer at PT. Takein Technology Indonesia**, developing TAKEIN with Go, Next.js, React, TypeScript, PostgreSQL, and Docker. Previously, I served as **Head Blockchain Developer at COE Smart Electronic Vehicle, Telkom University**, where I led the development of [TeaLabs](https://www.tealabs.my.id/) with PPTK Gambung.
